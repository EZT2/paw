# 🐾 PawAtlas

一个全球化的猫咪打卡与百科 App。让每一只流浪猫都有自己的数字档案。

![PawAtlas Logo](logo.png)

## 🌟 项目愿景
- **全球猫咪打卡**：在地图上记录你偶遇的小猫。
- **跨语言社区**：内置 AI 翻译，全球猫友无障碍沟通。
- **公益与救助**：为 NGO 提供精准的流浪猫数据支持。

## 🛠️ 技术栈
- **前端**: Flutter
- **后端**: Supabase (自托管在 Oracle Cloud)
- **地图**: Mapbox
- **AI**: Claude / Gemini
