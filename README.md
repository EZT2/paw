## 🌟 项目愿景 / Project Vision

### (中文)
- **全球猫咪打卡**：在地图上记录你偶遇的小猫。
- **跨语言社区**：内置 AI 翻译，全球猫友无障碍沟通。
- **公益与救助**：为 NGO 提供精准的流浪猫数据支持。

### (English)
- **Global Cat Tracking**: Map your encounters with local felines.
- **Multilingual Community**: Built-in AI translation for seamless global communication.
- **Welfare & Rescue**: Precise stray cat data support for NGOs and rescuers.

## 🛠️ 技术栈 / Tech Stack

- **前端 / Front-end**: Flutter
- **后端 / Back-end**: Supabase (自托管在 Oracle Cloud / Self-hosted on Oracle Cloud)
- **地图 / Maps**: Mapbox
- **AI**: Claude / Gemini
